Incremental planning estimates

Added Elements Cost Context (Informational)

The figures below are planning ranges for the added amenities and are presented for owner transparency. They are not a fixed contract guarantee.

$130k - $190k Spa incremental range when enabling deck/ramp/base prep is already covered in base scope.
$90k - $150k Splash-pad incremental range for a simple unheated concept.

What these ranges assume

  • Base pool-deck structural progression is already in motion.
  • Pump room capacity and heating capacity confirmations are already on file.
  • Spa planning reference currently shown in design package is approximately 14'-0" x 8'-6".
  • Recommended planning contingency remains 10% - 15%.

Combined added-elements envelope

  • Approximate combined incremental base range (spa + splash): $220k - $340k.
  • Total approximate cost with contingency is less than a quarter million dollars.
  • Relative to the last Special Assessment program, this added range is less than 2%.
  • Final values depend on bids, permitting, code review, procurement timing, and Board action.

Implementation options

Phasing and Funding Position

Option A: Execute added amenities as part of current cycle

  • Lower remobilization and rework risk compared with later retrofits.
  • Better coordination while site teams are already mobilized.
  • Potentially more efficient commissioning and schedule integration.

Option B: Defer added amenities, prepare now

  • Enable structural/surface readiness now to minimize future disruption.
  • Spa zone can operate as elevated lounge deck if spa vessel is deferred.
  • Splash zone can function as normal deck amenity area if splash system is deferred.
  • Future installation may include remobilization and inefficiency premium.

Current funding direction (informational)

  • The current Board position is that owners are not expected to need an additional special assessment to fund spa/splash added elements.
  • Expected sources discussed are available funds within Capital Improvements reserve line items and/or savings achieved in Special Assessment-funded project execution.
  • Any final implementation timing and funding commitment remains subject to Board approval, legal/financial controls, and final procurement outcomes.

If approved

Integrated path can proceed

Approval supports a single coherent design program and avoids piecemeal outcomes across the most visible common-area corridor.

If not approved

Alternative restoration path risk

Current engineering/legal planning indicates non-approval may require reverting to the prior existing configuration and reinforcing the pool deck to accommodate the former planter and tile loads. Preliminary planning assumes this could involve reinforcing approximately 27,000 square feet of pool deck area. Accordingly, the reinforcement cost impact could be well in excess of $1,000,000, subject to final engineering design, permitting/code review, and bid validation.

Frequently asked questions

FAQ

Are owners voting on exact final dollars in this question?

No. Owners are approving alteration/improvement direction. Final contracting values are determined through bids, permitting, and Board approvals.

Do owners need additional special assessment funds for spa/splash?

Current Board direction is no additional special assessment is expected for those added amenities, based on current funding assumptions and subject to final Board action.

Can added amenities be done later?

Yes. The page outlines a deferred path with enabling preparation now to reduce rework risk later.

Why include entry/rotonda tile continuity in this same question?

Because the arrival corridor and pool deck are visually connected. The intent is a coherent final aesthetic language across both areas.

What happens if this question is not approved?

Current planning indicates potential return to a prior-configuration restoration path with significant reinforcement implications; management currently estimates approximately $1,000,000 impact, subject to final validation.

Should owners submit their Limited Proxy even if they disagree?

Yes. Submitting your Limited Proxy ensures your position is recorded in the official tabulation.
