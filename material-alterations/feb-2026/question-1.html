Question 1 | Integrated Pool Deck and Entry Design Program

Pool, deck, spa/splash areas, and entry/rotonda tiled continuity

What You Are Voting On

Question 1 asks owners to approve the integrated common-area design program shown in Exhibit A, including the updated pool and pool deck composition, spa/jacuzzi area, splash pad area, and tiled pedestrian continuity at entry/rotonda-adjacent areas.

This page is intended to provide full owner-facing context for this question in one place: scope, visuals, practical impacts, cost planning references, and frequently asked questions.

Project Details

Current Project Baseline

  • The base pool deck project is already approved and under active construction.
  • Heavy construction is near completion; next phases include drainage, planters, waterproofing, and finishes.
  • Current management baseline target remains Q3 2026.
  • Base project funding is from the previously approved Special Assessment, with no additional procurement currently required for base completion.

Integrated Elements In This Question

  • Pool and pool-deck design and finish program.
  • Spa/jacuzzi area and splash pad area within the overall layout.
  • Pedestrian/ramp tiled continuity tying entry/rotonda area language to the new deck aesthetic.
  • Landscaping and amenity composition that create one coherent design outcome.

Added Element Cost Estimates (Informational)

These are incremental planning ranges for added elements beyond base contracted scope.

What Is Already Covered vs. What Is Incremental

  • Already in base project path: core deck structure work, drainage/waterproofing progression, pool equipment/pump-room program, and tile continuity program funded by the existing Special Assessment baseline.
  • Spa deck area context: the raised spa-deck zone can still function as usable amenity area (furniture/sunning) if the spa vessel is deferred or not installed.
  • Splash area context: surface preparation can be coordinated now so a future splash installation can avoid major tile removal and reduce waterproofing disruption risk.
  • Incremental estimates below: represent the added systems/equipment/permitting package for the spa and splash amenities themselves.

Spa / Jacuzzi | Incremental Added Scope

  • $130,000 - $190,000 estimated incremental installed range when raised deck/ramp/base preparation is already included in base scope.
  • $155,000 - $230,000 planning scenario if spa-specific deck/ramp/accessibility scope is not fully included in base work.
  • Current planning reference includes an approximately 14'-0" x 8'-6" spa concept (approx. 10-12 users).
  • Recommended contingency planning: 10% - 15%.

Splash Pad | Incremental Added Scope

  • $90,000 - $150,000 estimated incremental installed range for a simple unheated kids splash zone concept.
  • Range assumes base deck structure/preparation is addressed within the current project path.
  • Recommended contingency planning: 10% - 15%.
  • If deferred, remobilization/recommissioning can introduce an inefficiency premium versus concurrent execution.

Planning Envelope (Added Elements Only)

  • Combined incremental base range: approximately $220,000 - $340,000 (spa + splash, excluding the already-funded base deck progression).
  • Combined planning range with contingency: approximately $242,000 - $391,000 using 10% - 15% contingency assumptions.

Important: These figures are informational planning estimates for owner visibility. Final procurement values are determined through bids, permitting/code review, and Board contract administration.

Approval and Non-Approval Impact

If Question 1 Is Approved

The Association can proceed with this integrated design direction as a coordinated implementation path. This reduces piecemeal decision risk and supports consistent final appearance in the most visible common-area corridor.

If Question 1 Is Not Approved

Based on current engineering/legal direction, the Association may need to pursue a restoration path substantially consistent with prior configuration requirements. Management/engineering currently estimate this alternative path could introduce approximately $1,000,000 in additional reinforcement-related costs tied to prior planter/load conditions.

The above figure is an informational planning estimate and remains subject to final technical and contract validation.

FAQ | Question 1

Are owners voting on exact final contract dollars in this question?

Owners are approving the alteration/improvement scope and direction. Budget and implementation controls remain under Board and management administration subject to governing requirements.

Why are multiple components grouped in one question?

The current strategy treats these components as one integrated common-area program so the final outcome remains coherent and avoids patchwork approvals that can compromise execution continuity.

Which costs are already in the base project versus added elements?

Base pool deck completion remains under the existing approved project funding path. Spa and splash figures shown on this page are incremental added-element planning ranges for owner visibility.

What is the spa planning reference used in owner communications?

Current planning references include an approximately 14'-0" x 8'-6" spa concept. Informational planning ranges are included in the cost section on this page.

What is the splash pad planning reference?

Current planning assumes a simple, unheated kids splash-play zone concept in the designated area shown in the integrated visual package.

Do owners still need to submit a vote if they disagree or are undecided?

Yes. Owners should submit their vote so their position is counted in the final tally.
